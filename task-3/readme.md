# AI & ML Internship - Task 3

## Linear Regression

### Objective

The objective of this task is to implement Simple and Multiple Linear Regression to predict house prices.

### Dataset

Housing Price Prediction Dataset

- 545 rows
- 13 original columns
- Target: `price`

### Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Kaggle Notebook

### Work Done

- Loaded and explored the dataset
- Checked missing values
- Encoded categorical variables
- Split the dataset into training and testing data
- Built Simple Linear Regression using `area`
- Built Multiple Linear Regression using multiple features
- Evaluated the models using MAE, MSE and R²
- Created a regression line
- Created an Actual vs Predicted plot
- Interpreted regression coefficients

### Simple Linear Regression Results

- MAE: 1,474,748.13
- MSE: 3,675,286,604,768.19
- R² Score: 0.2729

### Conclusion

Linear Regression was successfully implemented to predict house prices.

Simple Linear Regression was used with `area` as the predictor, while Multiple Linear Regression used multiple features. The models were evaluated using MAE, MSE and R² scores.

The notebook contains the complete implementation, visualizations and results.
